# Bíblia VP — Verdade Prática

**Conheça a Verdade. Viva a Palavra.**

Aplicativo cristão de leitura, estudo e aplicação prática das Escrituras. O nome de apresentação **Bíblia VP** é provisório até a verificação de disponibilidade e marca.

## Recursos
- Bíblia offline, pesquisa, favoritos, histórico e anotações.
- Planos e preferências de leitura, incluindo texto extra grande.
- Estudos dos livros bíblicos e de palavras em seus idiomas originais.
- Ferramentas de esboços e preparação ministerial.
- Agenda, lembretes e checklist dos compromissos.
- Backup local e conta opcional com Firebase (login Google depende de configuração OAuth).
- Estrutura Premium de estudos, conteúdos e mentorias; cobrança real ainda não ativada.

## Desenvolvimento

```powershell
npm install
npx expo start --dev-client --clear
```

Consulte `docs/ACCOUNT-AUTH.md` para configurar a autenticação.

## Compatibilidade de instalações

O pacote Android `com.taysonaraujo.bibliasmart`, o slug Expo `biblia-mulher` e as chaves de armazenamento existentes foram **mantidos** deliberadamente para preservar compatibilidade com instalações e dados anteriores. Alterações do nome exibido no launcher exigem gerar um novo build Android.

## Identidade

Nome de exibição: **Bíblia VP**. Significado: **Verdade Prática**. Referências: João 17:17 e Tiago 1:22. A disponibilidade do nome deve ser validada junto ao INPI e nas lojas antes da publicação.
